# ZX Spectrum programming course

A hands-on course in ZX Spectrum programming, built by Dalix with Quintus (Grok Bot). It runs from the Spectrum's design through BASIC, POKE screen fills and Z80 machine code, to a Space Invaders-style game built first in BASIC and then in machine code, and a parameter-driven sprite engine.

Every program is tested in the Fuse emulator (48K) before it is committed.
