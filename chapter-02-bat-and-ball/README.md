# Chapter 2 — Bat and ball

A tiny bat-and-ball game in Sinclair BASIC, built in steps and tested in a 48K emulator at each step. The programs live in this folder. Start at step 1 and go on only when that step has been tried.

1. [A bouncing ball](step1-ball.md) — `step1-ball.bas` / `step1-ball.tap`
2. [A bat you can move](step2-bat.md) — `step2-bat.bas` / `step2-bat.tap`
3. [Coloured bricks](step3-bricks.md) — `step3-bricks.bas` / `step3-bricks.tap`
4. [A user-defined graphic for the ball](step4-udg-ball.md) — `step4-udg-ball.bas` / `step4-udg-ball.tap`
5. [A little random deflection](step5-random.md) — `step5-random.bas` / `step5-random.tap`
6. [BEEP sounds](step6-beep.md) — `step6-beep.bas` / `step6-beep.tap`
7. [Score, lives, and game over](step7-score.md) — `step7-score.bas` / `step7-score.tap`

A [wrap-up of the BASIC in this chapter](summary.md), and why we stop here and move to machine code, follows the steps.

The colour numbers used for the bricks are in the [colour reference](../colour-reference.md). The machine's memory map and attributes are in [Chapter 1](../chapter-01-the-machine/). To build a tape and run it in Fuse, see [tools/README.md](../tools/README.md).
